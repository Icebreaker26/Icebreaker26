## Sobre mí

Construyo sistemas de gestión **a medida** para empresas que necesitan dejar de operar en Excel.  
Cada producto arranca desde cero — pensado alrededor de los flujos reales de tu organización.

Actualmente en práctica profesional en **⚡ Enel Colombia** — Permitting & Detailed Design de Alta Tensión.
